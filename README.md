# Heritage-Treasures-An-In-Depth-Analysis-of-UNESCO-World-Heritage-Sites-in-Tableau
PROJECT TITLE:
UNESCO Heritage Sites Visualization & Web Integration

OVERVIEW:
A short description of the project:

This project was done as part of JNTUK & SmartBridge Internship (Data Analytics with Tableau).
It integrates Tableau dashboards and stories into a Flask-based website with Bootstrap.

OBJECTIVES:

✔ Analyze UNESCO Heritage Sites data

✔ Create Tableau visualizations (maps, top 10 charts, bubbles, etc.)

✔ Create dashboards & a story in Tableau Public

✔ Integrate these visualizations into a web application using Flask and Bootstrap

TECHNOLOGY STACK:

Tableau Public

Python Flask

Bootstrap

HTML, CSS

GitHub for version control

DATASET:

The dataset whc-sites-2019.csv (UNESCO Heritage Sites) was provided by SmartBridge.
Fields used: site name, region, area in hectares, criteria, etc.

VISUALIZATION BUILT:

✔ Map with bubbles by region (count of sites)

✔ Top 10 regions by area (bar chart or map)

✔ Tableau Story combining dashboards

WEB INTEGRATION:

✔ Embedded Tableau dashboards and story into a Flask website

✔ Responsive UI built with Bootstrap

✔ Hero sections, About page with images, and navigation menu
